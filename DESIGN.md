# Local transcription desk

An extension of the established warm manuscript desk: paper #faf9f6, forest #315949, DM Sans controls, Lora text, a compact recording library, flexible manuscript and optional checks/reference margin. Persistent playback and actual content-time status remain visible. Mobile collapses the library and offers explicit controls. Use clear local-save wording so people do not mistake it for shared cloud saving. File import replacement is an explicit preview dialog. No decorative imagery, fabricated audio information or new visual world.


Starter drafts extend the existing recording sidebar as a compact ruled list. Each entry names the session, marks the content as an initial transcript, offers a TXT download and enables Load matching draft only for the corresponding local recording. Loading opens the existing replacement preview; it never silently replaces browser edits. Small metadata and file controls retain the incumbent treatment.
